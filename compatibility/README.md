# Фиксация совместимости

`host-contract.template.json` — незаполненная форма, **не подтверждение совместимости**. Агент создаёт `host-contract.json` после M0/M4 и указывает точные значения. Секретные данные не сохраняются.

Evidence-протоколы оператора (probe-трейсы, smoke-раны, live-проверки, установка) ведутся локально в `local/evidence/` и в репозиторий не входят; в карточке и отчётах допускаются только ссылки вида «локальный evidence».

В `fieldMapping` записываются реальные выражения/пути SDK fields для capture/correlation; null означает «не установлено». Путь из примера или предположение не считается mapping.

`PASS` означает реальный выполненный тест на указанной версии. `FAIL` — получен конкретный неправильный результат. `NOT_RUN` — не было возможности/этапа; это не PASS. `NOT_APPLICABLE` требует письменной причины и не может заменять обязательный binding/permission test.

Для live auto обязательны все checks и отсутствие неразрешённых security blockers. В release/runtime admission хранится точная квалифицированная комбинация host/SDK/platform. Сам template нельзя просто скопировать и считать supportedHosts заполненным.

Первичная документация не закрепляет выдуманный диапазон semver V2. При обновлении достаточно повторить адресный host smoke и сохранить новый record; не требуется повторять весь обзор архитектуры.
